# Noryx

Simulador de carreras en el navegador (física a 500 Hz, monoplazas y GT3, carreras contra IA).

## Jugar
Publicado con GitHub Pages: `https://TU_USUARIO.github.io/noryx/play`

## Desarrollo
```bash
npm ci
npm run dev      # http://localhost:3000
npm run build    # exportación estática en ./out
```
Pasos para publicar: ver `LEEME_DESPLIEGUE.md`.
